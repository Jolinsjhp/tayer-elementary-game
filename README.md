# Still Serving · Tayēr + Elementary

An unofficial pixel-art bar tribute.

Play: https://Jolinsjhp.github.io/tayer-elementary-game/

Drag empty scene space to turn the camera; scroll to zoom. Click staff to talk and use Your evening to order, request water or visit WC. Tayēr requires an invitation. Sound starts after entry and can be switched off. Monica’s close-up returns to the running game.

This is a playable prototype: virtual orders, sample menu prices, fictional dialogue, simulated guests and traffic. Portraits are illustrated from public photo references; the poster is a pixel interpretation. Three.js retains its bundled licence.

The local project’s SDD is maintained separately in specs/.
