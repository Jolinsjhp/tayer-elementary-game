# Still Serving · 2D edition

Play: https://jolinsjhp.github.io/tayer-elementary-game/2d/

A preserved Phaser pixel-art edition of the unofficial Tayēr + Elementary fan game. The 3D edition stays at the repository root.

This is a playable prototype with fictional dialogue, virtual orders and archived sample menus. Later 3D character and animation refinements have not all been ported to this edition. No account or real payment is created.

Phaser 3.90.0 and inkjs 2.3.2 are bundled, retaining their source notices. Serve this folder over HTTP to run locally.
